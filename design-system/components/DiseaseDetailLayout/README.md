# DiseaseDetailLayout
Trang **chi tiết một bệnh** trong thư viện bệnh cây:

- Đầu trang: breadcrumb (Bệnh cây trồng / bộ phận / bệnh) → tên bệnh → nhãn (nhóm nguyên nhân, bộ phận, mùa) → mô tả ngắn → **4 ô thông tin nhanh**: mức nguy hiểm (thanh 5 nấc `sale`), cách lây, cây hay gặp, mùa. Bên phải: ô **Bắt bệnh cho cây**.
- **Triệu chứng theo bộ phận** (3 ảnh cận có nhãn — ảnh thật khi có).
- **Dễ nhầm với**: so sánh ngắn với bệnh/tình trạng tương tự để khách tự loại trừ.
- **Cách xử lý** dạng các bước đánh số + hộp lưu ý an toàn.
- **Sản phẩm xử lý** (lưới ProductCard) — mỗi thuốc hiện đủ liều, cách ly ở trang sản phẩm.
- Cuối trang: cách phòng, bài viết liên quan, kỹ sư kiểm duyệt (như ProductContent).
