# BuyBox
Khối mua bên phải trang chi tiết, theo đúng thứ tự của trang dược:

xuất xứ + nhà vườn/thương hiệu → **tên sản phẩm** 22px/700 → mã SP · điểm sao · số đánh giá · số hỏi đáp · đã bán → **giá** 28px `primary` kèm "/ đơn vị" → giá gạch + badge số tiền giảm → **chọn đơn vị** → (cây) **chọn kích thước** → **số lượng** → 2 nút → khối **Khuyến mãi được áp dụng** → mô tả ngắn 2–3 câu (chữ đậm cho ý chính) → SpecTable.

- Nút chính **Chọn mua** (`primary`, lg); nút phụ **Tư vấn Zalo** (`soft`) thay cho "Tìm nhà thuốc". Shop có cửa hàng thì thêm link "Xem tại vườn".
- Đổi đơn vị/kích thước thì giá, ảnh và quy cách đổi theo ngay.
- Khuyến mãi: đầu khối nền `warning-soft`, mỗi ưu đãi một dòng.
