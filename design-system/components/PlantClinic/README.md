# PlantClinic
Khối "Bắt bệnh cho cây", tương đương khối kiểm tra sức khỏe của trang dược: khách chọn triệu chứng → trả lời 3–5 câu hỏi → nhận chẩn đoán, cách xử lý và gợi ý thuốc/phân kèm nút mua.

- Đây là điểm khác biệt lớn nhất giúp bán thuốc BVTV và phân bón.
- Thẻ giới thiệu nền `primary-deep`; mỗi triệu chứng là một hàng có nút soft "Bắt đầu".
