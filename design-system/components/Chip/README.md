# Chip
Chip lọc nhanh và bộ chọn đơn vị tính.

- Chip lọc đặt ngay dưới tiêu đề danh mục; trạng thái chọn dùng `primary-soft` + viền `primary`.
- Bộ chọn đơn vị (segmented) dùng trên thẻ sản phẩm có nhiều quy cách: Chậu/Cây, Chai/Thùng, Bao 5dm³/Bao 20dm³. Giá trên thẻ đổi theo đơn vị đang chọn.
- Nhãn chip ngắn, tối đa 3–4 từ.
