# MobileCart
Giỏ hàng trên điện thoại:

- Thanh trên: quay lại, "Giỏ hàng (n)", **Sửa** (chuyển sang chế độ xóa nhiều).
- **Thanh freeship** ngay đầu.
- Nhóm **Cây sống** / **Vật tư – Thuốc – Phân** như desktop; mỗi dòng: ô tích chọn, ảnh 64px, tên 2 dòng, đơn vị (bấm để đổi), giá, bộ tăng giảm. Vuốt trái để xóa.
- Dòng **Ưu đãi** mở VoucherModal dạng toàn màn hình.
- **Thanh đáy dính:** tổng thanh toán (giá gốc gạch) + nút **Đặt hàng (n)**; bấm tổng tiền mở bảng chi tiết các dòng tiền.
- Dưới danh sách: "Thường mua kèm" cuộn ngang.
