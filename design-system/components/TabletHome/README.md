# TabletHome
Trang chủ trên tablet dọc (768–1023px, thiết kế ở 820px):

- **Header 1 hàng:** logo · nút **Danh mục** (mở SidebarMenu dạng bảng trượt từ trái) · ô tìm kiếm to · Giao đến.
- Nội dung giống desktop nhưng: CollectionStrip hiện ~8 mục, banner cao 180px, **QuickActions 6 ô**, **lưới sản phẩm 3 cột**, danh mục nổi bật 4 cột.
- Giữ **thanh điều hướng đáy** như mobile (dễ bấm khi cầm máy).
- iPad ngang (≥ 1024px) dùng giao diện desktop có SidebarMenu.
