# MobileOrders
Đơn hàng trên điện thoại:

- **Danh sách:** tab trạng thái cuộn ngang (có số đếm) → thẻ đơn gọn: ngày · mã · trạng thái; 1 dòng sản phẩm đại diện + "và n sản phẩm khác" + tổng tiền; chân thẻ có gợi ý (khung giờ giao, **bảo hành còn n ngày**) và 1–2 nút theo trạng thái.
- **Chi tiết:** đầu trang `primary-deep` với trạng thái lớn → **tiến trình dọc** (mới nhất ở trên) nổi đè lên đầu trang → dải **bảo hành cây** → **ảnh cây trước khi giao** → giao đến → sản phẩm → thanh toán. Thanh đáy: thành tiền + Đánh giá + Mua lại.
- Nút chat ở thanh trên mở Zalo kèm sẵn mã đơn.
