# Header
Header gọn 2 tầng trên nền `primary-deep`, đi cùng SidebarMenu (không còn hàng menu ngang trên desktop).

1. **Thanh chính**: logo, ô tìm kiếm chiếm phần lớn chiều ngang, ô **Giao đến** (chọn quận/huyện để tính phí và thời gian giao — cây sống giao xa rất khác giao nội thành), đăng nhập, giỏ hàng.
2. **Từ khóa gợi ý** (`on-deep-muted`): 6–8 từ phổ biến dưới ô tìm, đổi theo mùa vụ.

Header dính (sticky) khi cuộn. Mobile: logo + Giao đến + giỏ trên một hàng, ô tìm kiếm full width hàng dưới, danh mục mở bằng tab "Danh mục" ở thanh dưới cùng.
