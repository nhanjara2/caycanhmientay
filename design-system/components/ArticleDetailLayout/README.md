# ArticleDetailLayout
Trang **bài viết** Góc chăm cây, 3 cột: mục lục dính (220px) | bài (tối đa 720px, chữ 16px, dòng 27px — dễ đọc lâu) | cột phải dính (280px).

- Đầu bài: breadcrumb chuyên mục → tiêu đề 30px → đoạn dẫn → **tác giả + kỹ sư kiểm duyệt**, ngày cập nhật, thời gian đọc, nhãn Đã kiểm duyệt, Chia sẻ, Lưu.
- Trong bài: ảnh, tiêu đề mục, **khối "Dùng trong bài này"** (3 sản phẩm thêm vào giỏ ngay), hộp lưu ý an toàn khi nhắc tới thuốc.
- Cuối bài: "Bài viết có hữu ích?".
- Cột phải: **Bắt bệnh cho cây** (`primary-deep`) + bài liên quan.
- Mobile: mục lục thành nút nổi, cột phải xuống cuối bài.
