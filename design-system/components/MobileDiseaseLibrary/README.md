# MobileDiseaseLibrary
Thư viện bệnh cây trên điện thoại (bản mobile của DiseaseLibraryLayout):

- Ô **tìm theo triệu chứng** ở đầu.
- **Theo bộ phận:** hình cây của desktop thu thành hàng icon tròn cuộn ngang (Hoa, Lá, Quả, Thân, Rễ, Toàn cây); bộ phận đang chọn nền `primary`.
- Danh sách bệnh 1 cột kèm nhãn nguyên nhân, "Xem thêm" thay phân trang.
- **Theo nguyên nhân:** lưới 3 cột.
- Vào từ tab Bắt bệnh ("Tra thư viện bệnh") và từ Góc chăm cây.
