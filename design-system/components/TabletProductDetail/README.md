# TabletProductDetail
Chi tiết sản phẩm trên tablet dọc:

- **Giữ 2 cột như desktop:** ProductGallery (5 ảnh nhỏ, 2 cam kết) | BuyBox (chip kích thước, đơn vị, 2 nút).
- Mục lục bên trái của desktop chuyển thành **hàng tab dính** phía trên nội dung.
- Ẩn thanh điều hướng đáy; khi cuộn qua BuyBox hiện **thanh mua dính đáy** (giá, lựa chọn đang chọn, số lượng, Chọn mua).
- Thanh trên: quay lại + breadcrumb rút gọn + tìm + giỏ.
- Hộp thoại (địa chỉ, ưu đãi, bản đồ) trên tablet giữ dạng hộp giữa màn hình rộng 560px như desktop.
