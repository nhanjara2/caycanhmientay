# Badge
Nhãn nhỏ gắn trên thẻ sản phẩm và trang chi tiết.

- **sale**: phần trăm giảm giá, luôn ở góc phải trên ảnh sản phẩm.
- **origin**: xuất xứ (Đà Lạt, Thái Lan, Nhật Bản…), góc trái trên ảnh, giống cách trang dược phẩm hiện quốc gia sản xuất.
- **info**: đặc tính cây (Dễ chăm, Ưa bóng râm, Lọc không khí) hoặc loại thuốc (Hữu cơ, Sinh học).
- **success / danger**: tình trạng kho.
- **sun**: chỉ dùng trong khu Flash sale.
- Tối đa 2 badge trên ảnh, 3 badge đặc tính dưới tên.
