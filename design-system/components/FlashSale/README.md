# FlashSale
Khối khuyến mãi theo khung giờ: dải `sun` có đồng hồ đếm ngược, hàng khung giờ, lưới ProductCard kèm thanh "Đã bán".

- Khung giờ đang chạy dùng `sale`; các khung sau viền `border`.
- Thanh tiến độ thay dòng quy cách trên thẻ; nền `primary-soft`, phần đã bán `sun`.
- Chỉ một khối Flash sale trên trang chủ, đặt ngay sau QuickActions.
