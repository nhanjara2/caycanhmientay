# StoreLocatorLayout
Trang Hệ thống cửa hàng: Header → breadcrumb → tiêu đề + giờ mở cửa chung → 2 cột (StoreFinder 360px | StoreDetail).

- Mở từ nút "Xem danh sách cửa hàng" ở Footer, từ "Nhận tại vườn" ở trang thanh toán và từ trang tài khoản.
- Mỗi cửa hàng nên có trang riêng (đường dẫn theo tên cửa hàng) và dữ liệu cửa hàng khai báo đúng trên Google Business để khách tìm "cửa hàng cây cảnh gần đây" thấy được.
