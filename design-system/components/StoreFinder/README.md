# StoreFinder
Cột tìm cửa hàng, theo trang hệ thống nhà thuốc:

2 tab **Tìm cửa hàng** / **Gần bạn** (xin quyền vị trí, sắp theo khoảng cách) → ô tìm theo tên đường, phường, tỉnh thành → "hoặc chọn nhanh" tỉnh/phường → **chip lọc** (thêm cho shop cây: Vườn ươm, Có workshop, Đang mở) → danh sách kết quả dạng radio.

- Mỗi kết quả: tên, địa chỉ mới, địa chỉ cũ (nếu có), **trạng thái mở cửa** (`success` / `danger`), khoảng cách, nhãn loại.
- Chọn một kết quả thì StoreDetail bên phải đổi theo; mục đang chọn nền `primary-soft`.
- Mobile: danh sách ở trên, bấm vào mở StoreDetail thành trang riêng.
