# SearchSuggest
Hộp gợi ý hiện ngay khi gõ vào ô tìm kiếm trên Header (sau 2 ký tự, trễ ~150ms).

- **Cột trái:** gợi ý từ khóa (phần khớp in đậm) → **danh mục** liên quan kèm số lượng → **bệnh cây** trong thư viện (khách hay tìm theo triệu chứng) → tìm gần đây dạng chip (xóa được).
- **Cột phải:** 4 sản phẩm khớp nhất (ảnh, tên, quy cách, giá, nhãn Bán chạy) → 1–2 bài viết.
- Chân hộp: "Xem n kết quả cho …". Phím ↑ ↓ chọn, Enter mở, Esc đóng.
- **Ô trống khi vừa bấm vào:** hiện tìm gần đây + **tìm nhiều nhất tuần này** + từ khóa theo mùa.
- Hiểu **tiếng Việt không dấu** và lỗi gõ thường gặp ("tri nam" → "trị nấm", "monstara" → "monstera"); hiểu tên thường gọi khác (trầu bà lá xẻ = monstera).
- Mobile: mở màn tìm kiếm toàn màn hình với cùng các khối xếp dọc.
