# Reviews
Khối đánh giá: điểm trung bình + phân bố sao → chip lọc → danh sách đánh giá → "Xem thêm".

- Điểm trung bình 40px/700, sao màu `sun`, thanh phân bố nền `border` phần đầy `sun`.
- Chip lọc riêng cho shop cây: **Có ảnh thực tế** — ảnh cây khách nhận được là bằng chứng mạnh nhất cho người mua sau.
- Mỗi đánh giá: avatar chữ cái, tên, nhãn **Đã mua hàng**, thời gian, sao, nội dung, ảnh 64px, Hữu ích / Trả lời.
- Phản hồi của shop lồng bên dưới, nền `surface-sunken`, nhãn **Kỹ sư** nền `primary`. Nên phản hồi mọi đánh giá dưới 4 sao trong 24 giờ.
