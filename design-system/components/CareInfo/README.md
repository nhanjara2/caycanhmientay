# CareInfo
Khối thông số trên trang chi tiết, ngay dưới giá.

- **Cây**: 4 ô Ánh sáng, Tưới nước, Nhiệt độ, Độ khó.
- **Thuốc/Phân**: 4 ô Công dụng, Liều pha, Cây áp dụng, Thời gian cách ly, kèm hộp **Lưu ý an toàn** (`warning-soft`, icon `danger`) — bắt buộc với thuốc BVTV.
- Giá trị ngắn, 1–3 từ; chi tiết để trong tab mô tả.
