# MobileAuth
Đăng nhập trên điện thoại: màn **toàn màn hình** trượt từ dưới lên, nút ✕ để đóng; cùng các bước như AuthModal.

- Ô SĐT dùng bàn phím số; mã OTP tự điền từ tin nhắn (autofill).
- Chọn Google mở hộp chọn tài khoản Google của hệ điều hành / trình duyệt; xong quay lại bước **Thêm số điện thoại** với nút chính dính đáy.
- Trong app: đăng nhập được giữ lâu (không bắt đăng nhập lại mỗi lần mở).
