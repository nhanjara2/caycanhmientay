# BlogFeatureBlock
Biến thể khối chuyên mục kiểu tạp chí: 1 bài lớn bên trái (ảnh 16:10, tiêu đề 20px) + 4 bài nhỏ bên phải. Học theo khối "Người cao tuổi" của trang dược.

- Dùng cho chuyên mục cần nhấn mạnh theo thời điểm: **Cây theo mùa**, **Cây Tết**.
- Xen kẽ với BlogCategoryBlock để trang không đơn điệu (khoảng 3 khối thường thì 1 khối này).
