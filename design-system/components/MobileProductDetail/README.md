# MobileProductDetail
Chi tiết sản phẩm trên điện thoại (ẩn thanh điều hướng đáy):

- **Ảnh full width** vuốt ngang, nút quay lại / chia sẻ / giỏ nổi trên ảnh, nhãn ngày chụp tại vườn, bộ đếm "1/9 · Video".
- Khối thông tin: xuất xứ, sao, đã bán → tên 17px → giá 22px + giá gạch + % giảm → **chọn kích thước/đơn vị** dạng chip → 3 cam kết cuộn ngang.
- Dòng **ưu đãi** gộp một hàng, bấm mở danh sách ưu đãi.
- **Tab dính** khi cuộn: Chăm sóc · Mô tả · Thông số · Đánh giá · Hỏi đáp (thay mục lục bên trái của desktop). Với cây, tab Chăm sóc (4 ô thông số) đứng đầu; với thuốc là **Cách dùng & liều pha**.
- **Thanh mua dính đáy:** nút chat · Thêm vào giỏ (outline) · Mua ngay (primary). Nếu chưa chọn kích thước, bấm mở bảng chọn trước.
