# StaffDeliveryApp
App (hoặc web mobile) cho **tài xế giao hàng** — vai trò Giao hàng chỉ thấy phần này.

- **Chuyến đang chạy:** đầu trang `primary-deep` với tên chuyến, khung giờ, 3 số (điểm đã giao, tiền thu hộ, km còn lại) → danh sách điểm dừng theo tuyến; điểm hiện tại viền `primary` đậm, mở rộng với địa chỉ, **nhãn giao hàng** (loại cây, Hẻm nhỏ, Dễ vỡ, Thang máy), số tiền **COD**, 3 nút lớn: Gọi · Chỉ đường · **Đã đến** (hệ thống nhắn khách "tài xế đã đến").
- **Xác nhận giao:** **chụp ảnh cây tại nơi giao** (bắt buộc với cây sống) → danh sách kiểm tra với khách → thu tiền (tiền mặt / QR) → **Hoàn tất giao hàng**; hoặc "Không giao được" kèm lý do → đơn quay về bảng xếp chuyến.
- Nút to, chữ to, dùng được bằng một tay; tab đáy: Chuyến · Bản đồ · Thu tiền · Tôi.
