# AccountLayout
Khung chung cho mọi trang tài khoản: Header → breadcrumb → lưới 2 cột (AccountSidebar 290px | nội dung).

- Trang này **ẩn SidebarMenu danh mục**, thay bằng AccountSidebar.
- Nội dung phải đổi theo mục: ProfileForm, danh sách đơn hàng (tab theo trạng thái: Chờ xác nhận, Đang giao, Đã giao, Đã hủy), sổ địa chỉ, Vườn của tôi, Lịch chăm cây…
- Mobile: 1 cột; từ trang "Tài khoản" bấm vào mục thì mở trang con có nút quay lại.
