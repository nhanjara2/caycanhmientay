# DiseaseLibraryLayout
Trang **Tìm hiểu bệnh cây trồng**: Header → breadcrumb → tiêu đề canh giữa + dòng dẫn sang **Bắt bệnh cho cây** (PlantClinic) → ô **tìm theo triệu chứng** → PlantPartMap → DiseaseGroupGrid.

- Mỗi bệnh có trang riêng dùng ProductContent: mô tả, triệu chứng (kèm ảnh), nguyên nhân, cách phòng, cách trị, **thuốc và vật tư đề xuất** (lưới ProductCard), kỹ sư kiểm duyệt.
- Đây là nguồn truy cập lớn từ Google ("lá cây bị vàng mép", "rệp sáp trên sen đá"), nên mỗi trang bệnh cần tiêu đề và mô tả chuẩn SEO.
- Khi đề xuất thuốc BVTV, luôn kèm liều dùng, thời gian cách ly và hộp lưu ý an toàn.
