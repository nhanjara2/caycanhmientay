# NotFoundPage
Trang **404** (không tìm thấy): số 404 lớn `primary-soft` với chiếc lá thay số 0, tiêu đề vui nhẹ, giải thích ngắn, **ô tìm kiếm**, 2 nút Về trang chủ · Xem cây bán chạy.

- Sản phẩm ngừng bán không trả 404 mà giữ trang, ghi "Ngừng kinh doanh" và gợi ý sản phẩm tương tự (giữ thứ hạng Google).
- Trang lỗi hệ thống (500) dùng cùng khuôn, nội dung "Có lỗi xảy ra, thử lại sau ít phút" + hotline.
