# QuickActions
Hàng lối tắt ngay dưới banner, giống hàng "Cần mua thuốc / Tư vấn với dược sĩ / Đơn của tôi" của chuỗi nhà thuốc.

- 5–6 ô trên desktop, cuộn ngang 4.5 ô trên mobile.
- Icon nét trong vòng tròn `primary-soft`, nhãn tối đa 3–4 từ.
- Đặt các dịch vụ khác biệt của shop ở đây: tư vấn, bắt bệnh cây, tra cứu thuốc.
