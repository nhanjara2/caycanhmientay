# NewsListCard
Thẻ tin dạng ngang dùng cho danh sách bên dưới khối nổi bật: ảnh 200px (16:10) trái → nhãn chuyên mục + ngày → tiêu đề 16px → tóm tắt 2 dòng `ink-muted` → (tùy chọn) chân thẻ.

- Thẻ nền `surface`, bo `radius-lg`, cách nhau `space-3`, tải thêm khi cuộn hoặc nút "Xem thêm".
- Biến thể **khuyến mãi**: thêm nhãn trạng thái + thời gian áp dụng + nút **Xem thể lệ** / **Nhận ưu đãi** ở chân thẻ; chương trình đã kết thúc làm mờ, xếp cuối.
- Mobile: ảnh lên trên, full width.
