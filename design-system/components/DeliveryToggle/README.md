# DeliveryToggle
Công tắc 2 lựa chọn ở đầu trang thanh toán: **Giao tận nơi** hoặc **Nhận tại vườn/cửa hàng**.

- Chọn "Nhận tại vườn" thì khối Thông tin nhận hàng đổi thành danh sách cửa hàng + giờ lấy, phí vận chuyển về 0.
- Nếu giỏ có cây lớn chỉ giao nội thành mà địa chỉ ở tỉnh, tự gợi ý chuyển sang nhận tại vườn.
