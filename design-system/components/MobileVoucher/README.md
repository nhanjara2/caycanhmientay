# MobileVoucher
Hộp ưu đãi dạng **toàn màn hình** trên điện thoại (VoucherModal): nút đóng ✕ trái, ô nhập mã, danh sách 3 nhóm (Đang áp dụng / Có thể dùng / Không dùng chung được), công tắc dùng điểm thưởng, chân dính có tổng tiết kiệm + **Áp dụng**.

- Mở từ dòng Ưu đãi ở giỏ hàng, thanh toán, chi tiết sản phẩm.
- Tablet: giữ dạng hộp giữa màn hình như desktop.
