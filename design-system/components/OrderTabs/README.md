# OrderTabs
Tiêu đề "Đơn hàng của tôi" kèm nút tìm đơn và menu thêm, bên dưới là hàng tab trạng thái.

- 6 tab: Tất cả, Đang xử lý, Đang giao, Đã giao, Đã hủy, **Trả hàng – Bảo hành** (gộp đổi trả vật tư và bảo hành cây).
- Tab có đơn cần theo dõi hiện số đếm nhỏ `primary-soft`.
- Tab đang chọn: chữ `primary` đậm, gạch chân 2px. Mobile: cuộn ngang.
