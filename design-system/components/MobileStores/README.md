# MobileStores
Hệ thống cửa hàng trên điện thoại:

- **Bản đồ** phía trên (cao ~260px) với ghim từng cửa hàng; cửa hàng đang chọn ghim to `primary-deep`, cửa hàng đã đóng ghim xám.
- Chip lọc: Gần bạn, Vườn ươm, Có workshop, Đang mở.
- Danh sách thẻ cửa hàng sắp theo khoảng cách; thẻ đang chọn mở rộng với 3 nút: **Chỉ đường**, **Gọi**, **Đặt lịch** đến xem cây.
- Vuốt danh sách lên để thu bản đồ lại (bottom sheet).
