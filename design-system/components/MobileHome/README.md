# MobileHome
Trang chủ trên điện thoại, cùng thứ tự với desktop nhưng xếp 1 cột:

Header → **CollectionStrip** cuộn ngang (ảnh tròn 56px) → **Banner** trượt, có chấm chỉ trang → **QuickActions** 4 ô → **Flash sale** (dải `sun` + lưới 2 cột) → các khối nhóm hàng (tiêu đề + chip nhóm con cuộn ngang + lưới 2 cột + "Xem tất cả") → Bắt bệnh cho cây → Góc chăm cây (thẻ cuộn ngang).

- Thẻ sản phẩm mobile (`m-card`): ảnh vuông, badge nhỏ, tên 2 dòng, giá + **nút + tròn** để thêm nhanh vào giỏ (sản phẩm nhiều đơn vị thì nút mở bảng chọn đơn vị).
- Banner cao 132px, bo `radius-lg`, cách lề 12px.
