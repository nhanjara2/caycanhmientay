# ServiceDetailLayout
Trang **chi tiết một dịch vụ**, ví dụ Cho thuê cây văn phòng:

- **Bảng gói** 3 cột: tên gói, **giá theo đơn vị** (/ cây / tháng), danh sách có ✓ / ✗, nút chọn; gói nên chọn viền `primary` 2px + nhãn "Được chọn nhiều nhất". Gói lớn ghi "Liên hệ".
- **Máy tính ước tính** (riêng cho thuê cây): số cây (gợi ý theo diện tích), gói, thời hạn (giảm khi thuê dài), xuất VAT → ô kết quả `primary-soft` với **chi phí/tháng** và giải thích cách tính → **Nhận báo giá chính thức** (mở QuoteRequestForm điền sẵn).
- **Cây thường dùng** (ProductCard có giá thuê).
- Tiếp theo: công trình mẫu, câu hỏi thường gặp (FAQ), CTA.
- Dịch vụ thiết kế sân vườn thay bảng gói bằng **khoảng giá theo m²** và bộ sưu tập phong cách (nhiệt đới, Nhật, hiện đại, vườn rau).
