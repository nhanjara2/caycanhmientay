# MobileBlog
Góc chăm cây trên điện thoại:

- Chip chuyên mục cuộn ngang dính dưới thanh trên.
- **Bài nổi bật** ảnh 16:9 full width → **Video ngắn** cuộn ngang (thẻ dọc 112px, bấm mở trình xem toàn màn hình vuốt dọc như Reels) → danh sách bài dạng ảnh 96px + tiêu đề → các khối chuyên mục.
- Chủ đề nổi bật và đội ngũ chuyên môn chuyển xuống cuối trang.
- Trang bài viết: mục lục thành nút nổi "Mục lục", sản phẩm liên quan cuộn ngang cuối bài, thanh đáy có Chia sẻ + Hỏi kỹ sư.
