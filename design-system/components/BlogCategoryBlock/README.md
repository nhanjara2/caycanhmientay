# BlogCategoryBlock
Khối một chuyên mục trên trang Góc chăm cây, cấu trúc như trang dược:

tên chuyên mục (`primary`) | chuyên mục con → **Xem tất cả** → hàng trên: bài 1 (ảnh 4:3 + tiêu đề + tóm tắt 3 dòng) | bài 2 (không ảnh, tiêu đề + tóm tắt) → hàng dưới: 3 tiêu đề ngắn.

- Mỗi chuyên mục một khối, thứ tự theo lượt đọc.
- Bài thuộc Bắt bệnh cây, Thuốc & Phân bón gắn sản phẩm liên quan ở cuối bài (thuốc sinh học, phân, dụng cụ) để chuyển từ đọc sang mua.
