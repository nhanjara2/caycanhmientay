# MobileCategory
Màn **Danh mục** (tab thứ 2) — thay cho SidebarMenu trên điện thoại, kiểu màn danh mục 2 cột quen thuộc của app siêu thị:

- **Cột trái 92px** (`surface-sunken`): 9 nhóm cấp 1, icon + tên; nhóm đang chọn nền `surface`, viền trái `primary`.
- **Cột phải:** banner nhỏ của nhóm → nhóm con cấp 2 dạng lưới 3 cột (ảnh 60px + tên) → lối tắt tra cứu (với Thuốc BVTV: theo bệnh, theo hoạt chất, theo loại cây).
- Ô tìm kiếm ở đầu, tìm trong toàn bộ danh mục.
- Cuộn cột phải thì cột trái tự đổi nhóm tương ứng (cuộn liên tục qua các nhóm).
