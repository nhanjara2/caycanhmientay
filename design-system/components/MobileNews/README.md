# MobileNews
Trang Tin khuyến mãi / Truyền thông trên điện thoại:

- Chuyên mục con thành **chip cuộn ngang** dính dưới thanh trên.
- Bài nổi bật ảnh 16:9 full width, nhãn trạng thái + thời gian, tiêu đề.
- Danh sách thẻ ngang gọn (ảnh 104px, trạng thái, tiêu đề 2 dòng, thời gian).
- Bấm "Nhận ưu đãi" trong bài lưu thẳng voucher vào tài khoản, hiện thông báo nhỏ, không rời trang.
